## 🎯 Objetivos del 4º Cuatrimestre

### Objetivo General
Que los estudiantes de 4º cuatrimestre desarrollen habilidades para:
- Analizar problemas y diseñar soluciones algorítmicas
- Implementar aplicaciones web modernas usando React
- Comprender el ciclo completo de desarrollo de software
- Trabajar en equipo utilizando metodologías ágiles

### Objetivos Específicos
1. **Lógica y Algoritmos**: Diseñar algoritmos y diagramas de flujo para resolver problemas
2. **Desarrollo Web**: Crear interfaces interactivas con React y Tailwind CSS
3. **Gestión de Proyectos**: Aplicar metodologías ágiles (Scrum) en proyectos reales
4. **Colaboración**: Usar Git y GitHub para trabajo en equipo

## 🚀 Secuencia Didáctica

### Semana 1-2: Fundamentos y Lógica
- Introducción al desarrollo de software
- Algoritmos y pseudocódigo
- Diagramas de flujo
- **Práctica 1**: Diseño de algoritmos

### Semana 3-4: Ciclo de Vida y Metodologías
- Ciclo de vida del software
- Metodologías ágiles (Scrum)
- Roles y artefactos
- **Práctica 2**: Planificación de proyecto con Scrum

### Semana 5-8: Desarrollo Web con React
- Componentes y props
- Estado y hooks
- Routing con TanStack Router
- **Práctica 3**: Desarrollo de interfaz interactiva

### Semana 9-12: Proyecto Integrador
- Diseño de arquitectura
- Implementación en equipo
- Pruebas y depuración
- Despliegue
- **Práctica 4**: Proyecto final

## 🎮 Enfoque Pedagógico

Este material sigue un enfoque **aprender haciendo**:

1. **Retador**: Los desafíos son gradualmente más complejos
2. **Divertido**: Incluye gamificación y proyectos creativos
3. **Colaborativo**: Fomenta el trabajo en equipo
4. **Contextualizado**: Todo el contenido se relaciona con el proyecto base

## 🛠️ Requisitos Previos

- Conocimientos básicos de programación (Python o JavaScript)
- Conocimiento de HTML y CSS básico
- Acceso a una computadora con Node.js instalado
